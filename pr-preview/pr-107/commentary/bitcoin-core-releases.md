Since 22.0, the server that publishes Bitcoin Core has stamped each release's checksum file into the chain the day the binaries went up. The subject here is that file: SHA256SUMS, the digest of every binary the release shipped as, one line per platform. A proof of that one file is therefore a proof about all of them — any binary whose digest appears in it existed by the block the proof lands in — and the register's citation is the release date, written by the only clock in this book.

There is a pleasing circularity in it, and it is worth saying which way the circle runs. The software validated the block; the block dates the software. These are not the same claim, and no trust is shared between them — the proof would hold if the server lied about everything else it said, and the block would be valid had the release never shipped. What the circle actually closes is provenance: the chain is the one record of the release date that does not depend on the publisher's word, canonical for the very software being dated.

The server publishes each proof as it was stamped: pending, naming calendar servers rather than a block, because the aggregating transaction had not yet confirmed when the file went up. The proofs vendored here have been completed — each calendar asked for the rest of its branch, the answer spliced over the promise — which any holder of the pending file can do, or redo, for themselves. The chapters agree with the announcement dates to the day, which is the practice audited after the fact: had a release been stamped late, or restamped, the citation would say so, and nobody could quiet it.

Two releases in the register share a single section: their checksum files shipped the same day, and the calendar folded both digests into one aggregating transaction. The proofs remain distinct — same passage, different merkle paths, one per file — a reminder that what sits in the chain is one commitment per batch, not per document, and the proof is the part that makes it about *this* document. And the register thins as it goes back: releases the server no longer lists cannot be fetched and so cannot be cited, and everything before 22.0 predates the practice entirely. An honest register has edges, and these are where they are.
