A table of contents, written into the kind of place its own entries occupy. The witness carries 41,353 bytes of JSON: a `meta` object naming a collection — "Museum Outdoor," a hundred street-art photographs, a supply, an icon, a disclaimer about the honesty of its attributions — and a `data` array listing a hundred further reveal transactions, each with the attributes a catalogue would print: the artist credited, the city, the date, the dimensions.

None of that is a rule. A marketplace that recognizes this manifest groups those hundred inscriptions into a collection; one that reads it differently, or not at all, sees a hundred unrelated witnesses and one block of JSON. The chain holds the bytes either way — which is exactly the gap this appendix exists to keep visible. The fee tells the same story from the other side: the reveal paid 16,117 sats to move 10,000, because the value was never the output. It was the payload.
