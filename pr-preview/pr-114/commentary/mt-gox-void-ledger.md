The one ledger on this shelf with no address, because no address can write its script: `76a90088ac` — duplicate, hash, an empty push where twenty bytes of key-hash belong, then the equality check and the signature check. In late October 2011 Mt. Gox's withdrawal code built outputs like this in place of ordinary payments; no hash of anything is zero bytes long, so every coin that arrived is beyond spending, and was the moment it was mined.

Read whole by its scripthash, the record is exact: **23 outputs, 2,609.36304319 ₿, none ever spent — all in one chapter**, block 150,951, 28 October 2011: a batch of withdrawals queued by the same faulty code and mined together. The largest printing is 497 ₿; nine are 100 ₿ even, one of which is in the contents as its own entry (Mt. Gox pays the void); the smallest is 21 ₿. The total confirms to the satoshi the figure long reported from user genjix's Bitcointalk thread of the next day ("someone fucked up and lost a lot of money," in which Mark Karpelès admitted the error); the missing byte was traced publicly in Ken Shirriff's March 2014 analysis (righto.com).

A ledger is a set of scripts, and this one has no address at all: an address is the machine's rendering of a well-formed script, and this script is not well-formed — that is the whole story. The chain accepted it anyway, because the chain checks spends, not sends. What remains is a name only the bytes can write, and a record of one-way arrivals whose total confirms, to the satoshi, a figure that had rested on reporting since 2011.
